Methods and data quality

What these data represent

One precipitation reference point per federal unit. Values are not state-wide spatial averages. Source: Meteomatics API (source=mix); historical source homogeneity has not been established.

Trends are exploratory and cannot alone attribute changes to climate or support forecasts.

A consistent reference

Display filters change the visible series. Climatology, monthly categories, and trend inference use the fixed historical reference.

At least 10 valid years are required for reference statistics and trend analysis. This record is not a standard 30-year climate normal.

Five rainfall categories

Very dry: below P10. Dry: P10 to below P30. Normal: P30 through P70, inclusive. Wet: above P70 through P90. Very wet: above P90.

Linear percentiles are calculated by point and calendar month. Tied thresholds may reduce the number of represented categories. “Normal” is a historical range, not a guarantee of no impact.

Quality before statistics

Incomplete values remain missing, never zero. Monthly totals require all expected daily records; annual totals require all 12 complete months. Machine-learning scores describe held-out model performance, not future guarantees.
